# ZumenSearch
不動産図面管理システム - 物件情報と図面（マイソク・ファクトシート）PDFをデジタル管理。
（Under developement）

### 目的

1. 物件情報を募集・販売図面と共にローカル環境でデジタル管理し、自社物件だけではなく流通する他社物件の募集・販売図面を含め、物件検索、条件検索、貸主検索、宅建業者検索などを可能にする。
2. 不動産業務システムをモダンなWinUIで開発・実装できることの実証デモとすることを最低限クリアすべき目標とし、実際に実務に利用されるうるレベルの機能や利便性を想定する。
3. 将来的な不動産データ標準化を視野に入れ、API・プロトコル相互運用性のテスト用クライアント及びリファレンス実装となることを想定する。

### 背景

1. 不動産の募集・販売図面は従来の紙（マイソク・ファクトシート）からPDFファイル形式で流通・取得することが多くなった。しかし、それら他社もの含めた流通情報を図面（PDF）込みでデジタル整理するツールの存在が欠けている。もともと日本の不動産業務に関するツールはアプリストアを見てもまったく存在していない。

2. 現在のところ、[米国のRESO](https://note.com/torum/n/n7460f48b170f)などと異なり、日本の不動産物件データのドキュメントやAPI・プロトコルの仕様標準化の動きは無い。しかし将来的に仕様を検討する際に相互運用性の検証などの為にクライアント側とサーバー側のそれぞれテスト用のシステムが必要となる。仕様が策定された際には「リファレンス実装」も必要となる。

3. 日本では、不動産業の本来業務に関するソフトウェア・システムは少数の企業が提供する商用業務基幹アプリケーションに限られる。それも、使い勝手の悪いウェブベースのクラウド系不動産業務システムか、または古いWindows Formsという数世代前のデスクトップUIフレームワークをベースに作られた不動産業務システムのどちらか。クラウドのウェブベースの業務システムは利便性もあるが、ネイティブのアプリケーションと比較すると機能性・パフォーマンス・OS準拠のUI/UX・セキュリティ等々で劣ったもとのなる。その一方、既存のデスクトップのローカル業務システムはどれも古いWindows Formsのままで、WPFへ移行もされてこず、現在のマイクロソフト公式フラッグシップUIフレームワークであるWinUIというモダンなUIフレームワークへ移行や再構築がされていない。

### 技術的設計方針

* Windows App SDK（WinUI3）を使ったモダンUI。
* MVVM (Model-View-ViewModel) アーキテクチャ設計パターンを使い、XAMLのUIレイヤーとドメインロジックの分離・疎結合化。
* Generic Hostを使用してインフラストラクチャーを構成し、ライフサイクル管理とDependency Injection（依存関係注入）を行う。
* RDBMSとしてはSQLiteを利用し、将来的にWebAPIを介してのクライアント・サーバー3層構成に移行する際はローカルキャシュとして扱う。
* DDD (Domain-Driven Design：ドメイン駆動設計) を現実的な限り適用。
* Native AOTによるコンパイルを可能とし、起動速度の高速化とメモリフットプリントの最小化を図る。また、単体実行形式に加え、MSIX等のストア公開可能なパッケージ形式にも対応する。
* 住所・所在地等はデジタル庁が提供する「アドレス・ベースレジストリ」のデータを活用し、ドリルダウン形式で選択して住所を登録することで原理的に表記揺れが起きないようにする。

### プロジェクト構成

`Src` 以下は単一の WinUI プロジェクト。Clean Architecture を目指して内部の責務を整理中。レイヤー間の依存関係も今後整理。落ち着いたらTestも整備予定。

* `Application`：アプリケーション設定、検索結果、処理結果に関するモデル。
* `Domain`：業務上のエンティティ、列挙型、値オブジェクト。物件や募集情報などのエンティティは `Entities` 以下に業務分野別に配置。
* `Infrastructure`：データアクセス、設定の保存・読み込み、プラットフォーム関連の処理。
* `Presentation`：業務機能別の画面・ViewModel・表示用モデル、検索画面、シェル、ダイアログ、UI サービス、ファクトリーなど。
* `Assets` と `Data`：実行時のパスを維持するため既定の場所に配置。

主な業務分野：

* **賃貸**（Rent）
- 賃貸住居用（Residentials）
- 賃貸事業用（Commercials）
- 賃貸駐車場（Parkings）
- 貸主（Lessors）
* **売買**（Sale）
- 売買住居用（Residentials）
- 売買事業・投資用（Commercials）
* **宅建業者**（Brokers）

### 現在の進捗（2026-11-18）

* **メイン画面**：ナビゲーションから各種検索画面へ移動、総合検索、最近の物件、エラー通知、ウィンドウの位置・サイズ設定の保存等は実装済み。
* **複数ウィンドウでの編集**：住居用・事業用の物件と募集情報に加え、貸主・宅建業者もそれぞれ専用の編集画面を持ち、複数の編集画面を開いて作業できる。物件と募集情報の親子連携や、保存後の検索・表示更新にも対応している。
* **賃貸住居用（Residentials）**：物件・募集情報の編集や保存、複製、検索、写真・PDF図面・連絡先の取り扱いなどを継続的に整備中（ほぼ完成）。
* **賃貸事業用（Commercials）**：物件・募集情報の仮入力のみ。詳細な検索条件は、必要なデータと検索仕様が整ってから実装予定。募集情報の複製機能も未実装。
* **賃貸駐車場（Parkings）**：未実装。
* **貸主（Lessors）・宅建業者（Brokers）**：それぞれ独立した検索画面・検索結果画面と詳細編集画面を備え、個別情報の検索・表示・編集を行える。物件情報に関連付けられた貸主・仲介業者情報の編集にも対応している。
* **売買（Sales）**：未実装。
* データベースは新しいスキーマでの初期作成を対象としており、開発中で未確定の項目が多いためマイグレーション処理は現在のところ実装していない。
