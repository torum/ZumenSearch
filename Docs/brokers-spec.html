Property and listing associations

The association table links a broker to a property or a particular listing. In the residential editor, an empty listing ID denotes a property-level link; an actual listing ID denotes a listing-level link. The same broker can have distinct links at both levels.

FieldDescriptionDatabase column
BrokerLinked broker ID.brokers_properties_listings.broker_id
PropertyLinked property ID.brokers_properties_listings.property_id
Property contextContext of the linked property.brokers_properties_listings.property_context_type
ListingLinked listing ID, or empty for a property-level link.brokers_properties_listings.listing_id

The composite primary key is (broker_id, property_id, listing_id). The schema declares a cascading foreign key to the broker table; it does not declare property or listing foreign keys.
