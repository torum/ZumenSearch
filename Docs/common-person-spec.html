Common person: input and database specification

Draft — implementation snapshot, not an approved schema. This sheet documents the fields shared by the rental lessor and broker editors as of 2026-11-22. Japanese labels are taken from the UI; descriptions are in English. No generalization to other person types is implied.

Each row identifies columns in two separate tables. A lessor is stored in rent_lessors; a broker is stored in brokers. These are not a shared database row. See the lessor and broker sheets for IDs and associations.

Person and name

Input fieldDescriptionDatabase columns (lessor; broker)
個人 / 法人Choose a natural person or legal entity; determines which name and contact inputs are shown.rent_lessors.person_kind; brokers.person_kind
姓Natural person's family name; marked required.rent_lessors.name_last; brokers.name_last
名Natural person's given name.rent_lessors.name_first; brokers.name_first
会社名Legal entity's company name; marked required.rent_lessors.name_company; brokers.name_company
法人格Company legal form, for example 株式会社.rent_lessors.name_company_type; brokers.name_company_type
法人格の位置Legal form before or after the company name: 前付け / 後付け.rent_lessors.name_company_type_position; brokers.name_company_type_position
Display name (derived)Combined name assembled from the selected person type's name inputs; not a separate input.rent_lessors.name; brokers.name

On save, each path clears the fields belonging to the other person type, including mobile number for legal entities and contact name for natural persons. The position control uses selected index 0 for 前付け and 1 for 後付け.

Address

These are person addresses, not property addresses: their table columns and persistence are separate from the common property location.

Input fieldDescriptionDatabase columns (lessor; broker)
郵便番号Postal code.rent_lessors.location_postal_code; brokers.location_postal_code
都道府県Selected prefecture name.rent_lessors.location_prefecture; brokers.location_prefecture
郡+市区町村Selected county and city.rent_lessors.location_county, rent_lessors.location_city; brokers.location_county, brokers.location_city
政令市区+大字・町名Selected ward and town area.rent_lessors.location_ward, rent_lessors.location_oaza; brokers.location_ward, brokers.location_oaza
丁目Selected chōme.rent_lessors.location_choume; brokers.location_choume
小字・番地以下Remaining address, such as block and building numbers.rent_lessors.location_edaban; brokers.location_edaban
住所プレビューRead-only address assembled from selected parts; the editor copies the preview to the person address when saving.rent_lessors.location_full; brokers.location_full
Machiaza ID (derived)Selected chōme, town or city ID, in that priority order; not a separate input.rent_lessors.location_machiaza_id; brokers.location_machiaza_id

Notes and sources

  • Person kind is stored as enum text; legal-form position is stored as an integer. Names and addresses have both component columns and assembled display values.
  • Fields in the fresh schema are NOT NULL; column defaults are storage defaults, not a statement of UI validation. The broker person_kind column has no default, unlike the lessor column.
  • Sources: Src\Presentation\Features\Rent\Lessors\Views\BasicPage.xaml, Src\Presentation\Features\Brokers\Views\BasicPage.xaml and their view models; Src\Infrastructure\DataAccess\DataAccessService.cs schema and person save/load paths.
