ZumenSearch specifications

Drafts. These sheets describe the current implementation and are not finalized database schemas.

Common specifications

  • Common property — shared identification, location, transportation and system fields.
  • Common person — name, contact and address fields shared by lessors and brokers.

Feature specifications

  • Rent Residentials — property and listing fields, facilities and linked records.
  • Rent Commercials — pre-rewrite snapshot of property and listing fields.
  • Rent Parkings — planned specification placeholder.
  • Rent Lessors — lessor records and property/listing associations.
  • Sale Residentials — early implementation and schema snapshot.
  • Sale Commercials — planned specification placeholder.
  • Brokers — broker records and property/listing associations.
