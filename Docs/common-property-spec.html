Common property: input and database specification

Draft — implementation snapshot, not an approved schema. This sheet documents the shared properties table and the current rental residential and commercial property editors as of 2026-11-22. Other property types may be incomplete or use different persistence; their behavior has not been verified here.

Labels are taken from the Japanese UI; descriptions are in English. A column's presence does not guarantee that every editor saves it. See Rent Residentials specification for residential-specific fields and related records.

Location

Residential and commercial rental editors expose the same location labels. Address selections provide component names and, where applicable, the shared machiaza ID; the prefecture selection also provides a municipality code.

Input fieldDescriptionDatabase column(s)
都道府県Selected prefecture name and municipality code.properties.location_prefecture, properties.location_prefecture_code
郡+市区町村Selected county and city or municipality.properties.location_county, properties.location_city, properties.location_machiaza_id
政令市区+大字・町名Selected ward and town area.properties.location_ward, properties.location_oaza_cho, properties.location_machiaza_id

Postal code (no input on these pages)Address model's postal code; both rental property save paths write it.properties.location_postal_code

location_machiaza_id is one shared column for the selected address hierarchy, not a separate ID for each selection. The editors save the selected chōme's master ID, or an empty ID if there is no selected chōme. location_prefecture_code stores the selected prefecture object's municipality code.

The location master is authoritative. When saved address components do not match it, the editors leave those components unselected and warn that saving removes the undisplayed components. Missing or unavailable master data is also reported; other property fields continue to load. Changing a parent selection clears its dependent selections. The remaining-address field and postal code are independent of these selections.

Transportation

Both rental editors offer four entries, selected with 交通１–交通４. The selector is UI-only. In the table, N means 1, 2, 3 or 4: for example, properties.train1_line_code. The buss spelling and capital letters are the current schema names.

Input fieldDescriptionDatabase column(s)
路線Rail line selected through a picker; code and name are saved.properties.trainN_line_code, properties.trainN_line_name
駅名Station selected through a picker; code and name are saved.properties.trainN_station_code, properties.trainN_station_name
駅から徒歩（分）Walk from station, in minutes.properties.trainN_ekitoho
バス停名Bus stop name.properties.bussN_stop_name
バス乗車時間（分）Bus ride, in minutes.properties.bussN_Jyousya
バス停から徒歩（分）Walk from bus stop, in minutes.properties.bussN_Toho

Property IDInternal primary key identifying the property; not the real-estate identifier entered above.properties.property_id
Property context typeApplication property context, such as residential or commercial rental; distinct from a property-kind input.properties.property_context_type
Thumbnail filenameStored thumbnail filename; the image path is resolved from the filename and base path rather than stored as a separate path column.properties.thumbnail_filename

Created atCreation timestamp; the schema supplies a default.properties.created_at
Updated atLast update timestamp; the schema supplies a default and application save operations also write it.properties.updated_at

In the fresh schema these columns are NOT NULL: transport times are INTEGER with default 0; other shared values are TEXT, generally defaulting to an empty string. The primary key has no default, and timestamp defaults are SQLite date-time expressions. These storage defaults do not imply that fields are optional or valid in the UI.

Implementation differences to review

  • Postal code: neither rental location page has a postal-code input; both save paths write the address model's postal code.
  • Transportation validation: both rental editors use the same named paste and text-change handlers for transportation times, along with numeric input scopes and four-character limits.
  • Property-specific fields, listing fields, contact associations and attachment metadata are outside the shared properties table; see the residential sheet for that editor's mappings.
