Rent Residentials: input and database specification

Draft — implementation snapshot, not an approved schema. This sheet documents the current residential rental property and listing editors and fresh SQLite schema as of 2026-11-22. Field labels are the Japanese labels shown in the UI; descriptions are in English. A database column is not a guarantee of validation or a finalized design.

Columns are qualified as table.column. Paired columns represent separate inputs, such as a value and its unit. Display-only or indirectly stored values are identified explicitly. System IDs, timestamps, and unrelated standalone contact-editor fields are not an exhaustive schema inventory. Attachments are represented by metadata and filenames, not document contents.

See also the common property specification for shared property fields and implementation differences.
